# Pretendard

Unmodified Pretendard Variable 1.3.9, self-hosted with `next/font/local`.

- Author and source: https://github.com/orioncactus/pretendard
- Binary: https://cdn.jsdelivr.net/npm/pretendard@1.3.9/dist/web/variable/woff2/PretendardVariable.woff2
- License: SIL Open Font License 1.1, included in `OFL.txt`.

The full Korean character set supports player and champion names without a build-time text subset. Geist is used for prominent numerical scores. Receipt exports use the loaded body font so Korean typography stays consistent with the site.
